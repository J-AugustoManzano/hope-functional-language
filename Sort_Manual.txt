----------------------------------------------------------------------
bitonicSort : list alpha -> list alpha
----------------------------------------------------------------------
Descrição:
  Classificação baseada em divisão recursiva e intercalação
  ordenada de subsequências.

Exemplos:
  bitonicSort([7, 3, 9, 1]); → [1, 3, 7, 9]
  bitonicSort(["C", "A", "B"]); → ["A", "B", "C"]


----------------------------------------------------------------------
bubbleSort : list alpha -> list alpha
----------------------------------------------------------------------
Descrição:
  Classificação por trocas sucessivas entre elementos adjacentes.

Exemplos:
  bubbleSort([7, 3, 9, 1]); → [1, 3, 7, 9]
  bubbleSort(["C", "A", "B"]); → ["A", "B", "C"]


----------------------------------------------------------------------
cycleSort : list alpha -> list alpha
----------------------------------------------------------------------
Descrição:
  Classificação baseada no reposicionamento cíclico dos elementos.

Exemplos:
  cycleSort([7, 3, 9, 1]); → [1, 3, 7, 9]
  cycleSort(["C", "A", "B"]); → ["A", "B", "C"]


----------------------------------------------------------------------
combSort : list alpha -> list alpha
----------------------------------------------------------------------
Descrição:
  Variante do Bubble Sort utilizando saltos progressivamente
  menores entre comparações.

Exemplos:
  combSort([7, 3, 9, 1]); → [1, 3, 7, 9]
  combSort(["C", "A", "B"]); → ["A", "B", "C"]
